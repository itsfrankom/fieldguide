## Publishing

Version 0.9 is a lightweight static HTML/CSS prototype, with no build dependencies. GitHub Pages can serve it from the repository's `main` branch root. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. GitHub will display the live URL once deployment finishes.

Article content is informational and does not replace property inspections, legal advice or individual professional guidance.
